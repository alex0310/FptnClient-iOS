# Дизайн

## Принцип

Интерфейс не копирует Android/iOS-клиенты FPTN. Визуальная метафора — не
«щит с замком», а **орбита**: соединение это состояние системы, а не кнопка.
Центральный orb показывает статус, вокруг него вращаются пунктирные орбиты,
а ниже — только те данные, которые нужны для решения «подключено / не
подключено» и «куда идёт трафик».

## Две темы

### Aurora

- глубокий сине-зелёный фон;
- акцент: mint + electric blue;
- ощущение холодного света и воды;
- подходит для тёмной комнаты и OLED.

### Ember

- тёплый графит;
- акцент: amber + coral;
- меньше синего свечения, ниже утомляемость вечером;
- альтернатива для пользователей, которым «неоновый» Aurora слишком ярок.

Темы переключаются в Settings и сохраняются в `SharedSettings.theme`.
Обе темы используют один набор компонентов, поэтому добавление третьей темы
сводится к новой `ThemePalette`.

## Экраны

### Tunnel

- orb с анимацией и статусом;
- заголовок состояния и короткое объяснение;
- кнопка Connect/Disconnect;
- три плитки: число серверов, режим пула, split tunnel;
- карточка automatic race;
- переключатель local network bypass.

### Servers

- список endpoint'ов из токена;
- country code, host:port, badge `REALITY` для censored zone;
- pin для справки;
- кнопка возврата к automatic race.

### Settings

- access token: import/replace/remove;
- appearance: две темы с превью;
- tunnel: dual/triple, plain/obfuscated/reality, split tunnel;
- language: system, English, Русский;
- diagnostics;
- about.

### Diagnostics

Показывает состояние VPN, выбранный сервер, режим, split CIDR, версию протокола
и параметры keepalive/lifetime. Это не отладочный лог с секретами.

## Компоненты

- `GlassCard` — полупрозрачная карточка с тонкой рамкой;
- `StatusPill` — статус с точкой и свечением;
- `PrimaryButton` — градиентная capsule-кнопка;
- `StatTile` — компактная метрика;
- `ThemeSwatch` — превью темы;
- `ConnectionOrb` — анимированный статус.

## Локализация

Все пользовательские строки вынесены в `FptnShared` (`Localizer` и словари
`en.lproj`/`ru.lproj`). В Settings можно выбрать системный язык, English или
Русский; выбор сохраняется в `SharedSettings.language` и применяется сразу,
без перезапуска. Технические названия протокола (`FPTN`, `TLS`, `REALITY`)
не переводятся.

## Доступность

- Все интерактивные элементы имеют текстовые подписи.
- Orb имеет `accessibilityLabel`.
- Контраст текста проверен для обеих тем.
- Анимации не несут единственный смысл: статус продублирован текстом.
- Размеры шрифтов заданы через `system(size:)`; при необходимости можно
  перейти на Dynamic Type, заменив на `.font(.headline)` и т.п.
